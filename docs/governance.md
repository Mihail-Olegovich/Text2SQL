## Защита от инъекций и контроль действий

**SQL-инъекции:**

- Инструмент выполнения запросов открывает соединение без флага `PRAGMA writable_schema` и не допускает DDL/DML — только SELECT
- Запросы выполняются в read-only режиме (`sqlite3.connect` без записи)
- Перед выполнением проверяется, что запрос не содержит модифицирующих операторов (`INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER`)

**Ограничение действий агента:**

- Агент не имеет доступа к инструментам, изменяющим данные
- Максимальное число шагов агента ограничено конфигурируемым параметром для предотвращения бесконечных циклов
- Результаты инструментов усекаются до 50 строк для предотвращения утечки больших объёмов данных через контекст модели
